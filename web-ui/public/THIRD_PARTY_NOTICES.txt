Codeflare Chat — third-party source notice

This frontend embeds selected source from Pi Agent Dashboard 0.11.0:
https://github.com/BlackBeltTechnology/pi-agent-dashboard
Commit: f93a27812534b2c1e2465dff52172fa763d631dd

The original source-only chat-embed interface is used, not the published web
application dist. The retained source, original package metadata, original-file
SHA-256 values and local-change inventory are in src/chat/upstream/.

Local adaptations are limited to React JSX compilation metadata, host-cookie
authentication options on the existing transport, a session-action update seam,
a supplied host theme, a question-request transport seam, and scoped overlay
hosting. Upstream event reducers, replay folding, reconnect/backoff and the
never-sent-only outbox are retained. The Dashboard application shell is not used.

Dashboard client-utils and dashboard-plugin-runtime are retained source inputs
from the same pinned commit, resolved through their declared public entries by
ordinary Vite and TypeScript aliases. Their original package manifests are kept
as inert provenance, not installed packages; their Vite 6 tooling peers are not
part of this application. Dashboard shared remains a registry dependency pinned
to 0.11.0. Codeflare keeps Vite 8. React/React DOM and the other rendering
dependencies retain their respective package license notices.

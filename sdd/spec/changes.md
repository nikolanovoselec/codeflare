# Spec Changes

Semantic changes to the specification. Git history captures diffs; this file captures intent.

## 2026-07-20

- **CI pipeline restructured into parallel path-filtered lanes with a fail-closed backend test gate** ([REQ-OPS-003](operations.md#req-ops-003-pr-checks-run-lint-test-typecheck-and-security-audit); Implemented). PR Checks split from one serial job into parallel lanes (quality, typecheck, two backend vitest shards, frontend, landing, host), each gated by a diff path filter and aggregated by a `summary` job that publishes the required `test` status context. The Workers-pool teardown-crash guard — formerly duplicated grep-on-prose in test.yml and deploy.yml — becomes one composite action gated by the machine-readable vitest JSON report: a non-zero exit is accepted only with a parsed report showing >0 tests, 0 failures, and the exact crash fingerprint; a missing or corrupt report fails closed. The host-test CI exclusion list moves from an inline workflow regex to `host/__tests__/ci-excluded.txt`.

- **Deploy pipeline staged; container image builds are content-addressed and reused** ([REQ-OPS-001](operations.md#req-ops-001-deploy-workflow-trigger-and-pre-deploy-pipeline), [REQ-OPS-002](operations.md#req-ops-002-docker-image-build-vulnerability-scan-and-registry-push), [REQ-OPS-013](operations.md#req-ops-013-deploy-command-and-post-deploy-hooks), [REQ-SEC-011](security.md#req-sec-011-container-image-scanned-for-cves-before-deploy); all stay Implemented). Deploy runs as prepare → (worker-asset build ∥ container image) → deploy, and no longer re-runs the test suite it already gates on via workflow_run. The container build/scan/push moves to a reusable `container-image.yml` parameterized by registry (`registry: dockerhub` dispatch input replaces the deleted `deploy-dockerhub.yml` near-copy). Images are tagged `in-<hash>` over every Dockerfile COPY source plus an ISO-week salt: identical-input deploys reuse the already-scanned image (a COPY-coverage guard disables reuse if the hash list goes stale; the weekly salt bounds agent-@latest and CVE-verdict staleness at seven days). Worker secrets upload in one `wrangler secret bulk` call, a post-deploy `/health` smoke gates success, and the registry prune script moves to `scripts/ci/prune-registry.mjs`.

- **Oversized backend test files split along describe boundaries** (no REQ semantics changed; anchors repointed). The four >1,500-line files break up verbatim — `routes/setup.test.ts` (2,908 → 558) into `setup-domain-routing`, `setup-provisioning-flows`, `setup-enterprise-groups`, and `setup-access-provisioning`; `container/index.test.ts` (2,335 → 1,158) into `enterprise-llm` and `lifecycle`; `lib/agent-seed-manifest.test.ts` (1,595 → 527) into `agent-seed-multi-agent` and `agent-seed-pi-memory`; `fuzz/input-validation.fuzz.test.ts` (2,284 → 1,188) into `replicated-helpers.fuzz` and `runtime-config.fuzz`. Blocks moved unchanged (shared scaffolding replicated per file — vi.mock hoisting is per module); every `@test` anchor and Verification link citing a moved block was repointed and truth-checked against the new files. Test counts are unchanged.

- **Scripted e2e suite removed** (REQ-OPS-004 and REQ-OPS-015 deleted from `operations.md`). The vitest+puppeteer e2e layer (`e2e/api`, `e2e/ui`, `vitest.e2e.config.ts`, `e2e.yml`, `host/__tests__/workflow-e2e.test.js`) is removed: it was dispatch-only, fully serial, and fail-open (`describe.skipIf(!isSetup)` turned a failed setup probe into a green run with zero tests). The k6 stress suites it housed move to `stress/`; the deploy-time service-auth secret and KV service-user seeding stay (the stress workflow authenticates with them). Surviving unit-test anchors keep [REQ-TERM-021](terminal.md#req-term-021-synchronized-output-frame-atomicity) and [REQ-LANDING-006](landing.md#req-landing-006-enter-the-matrix-sign-in-cta) verified; their deleted e2e anchors are dropped. **Status:** REQ-OPS-004, REQ-OPS-015 deleted.

## 2026-07-19

- **Synchronized-output frames now reach xterm atomically** ([REQ-TERM-021](terminal.md#req-term-021-synchronized-output-frame-atomicity), new; Implemented). A DEC 2026 frame split across terminal WebSocket messages is reassembled at ingest and delivered in exactly one write, so xterm's synchronized-output timeout can no longer paint a partially rebuilt transcript mid-replay — the "viewport walks through the entire scrollback" flash during Pi full redraws is gone, and the zero-delta bottom anchor now clears the stale post-`3J` scroll lock instead of no-opping. Per [AD111](../../documentation/decisions/README.md#ad111-synchronized-output-frames-are-delivered-atomically-at-the-write-boundary).

- **The Enter-the-Matrix CTA chrome now grows with the churn on an out-of-flow shell** ([REQ-LANDING-006](landing.md#req-landing-006-enter-the-matrix-sign-in-cta); Implemented). AC5 replaces the fixed-box overlay contract: the visible border and background move to an absolutely-positioned shell that shrink-wraps the churning words, so the button visibly expands and contracts with each frame — symmetrically and out of flow — while the in-flow anchor keeps its resting box and every navigation link stays fixed (AC6 unchanged). Supersedes the same-day fixed-box revert: sibling stability is preserved without giving up the growth flourish.

- **The Enter-the-Matrix CTA returns to a fixed resting box with symmetric overlay spill** ([REQ-LANDING-006](landing.md#req-landing-006-enter-the-matrix-sign-in-cta); Implemented). AC5 replaces the border-grows contract with a fixed-box overlay contract and AC6 drops the reserved header slot: the in-flow growth plus its 16rem desktop reservation displaced the five navigation links, and the churn overflow it accommodated is small enough to spill symmetrically past the border instead. Navigation links return to their pre-expansion positions.

- **Known-vulnerability allowlist gains bundled adm-zip acceptance** ([REQ-SEC-011](security.md#req-sec-011-container-image-vulnerability-scanning); Implemented, allowlist mechanism unchanged). `.trivyignore` accepts CVE-2026-39244 (adm-zip 0.5.17 DoS) as a bundled dependency inside foundry-local-sdk's published tarball in the vendored Pi agent tree — unreachable from any repo lockfile or override; blast radius is the user's own single-tenant session container.

- **Terminal scrolling is buffer-authoritative on every route and held output ring-drops** ([REQ-TERM-014](terminal.md#req-term-014-terminal-scroll-anchoring-under-scrollback-trimming) and [REQ-TERM-016](terminal.md#req-term-016-terminal-pane-reconnect-and-resize-authority); Implemented). AC3 now releases the hold in bounded slices with mid-release re-deferral; new AC5 makes the held-output cap drop oldest chunks so a reader is never written through; new AC6 moves keystroke re-anchoring from xterm's `scrollOnUserInput` to an app-owned `onData` path covering every input route; new AC7 intercepts the mouse wheel and scrolls the buffer service directly with alternate-buffer and zoom passthrough. The pre-existing resize-frame ACs relocate to REQ-TERM-016 (AC4/AC5), keeping REQ-TERM-014 a single scroll-anchoring concern within the seven-AC cap; this closes the two remaining desktop "snap to top" mechanisms (DOM scroll-state divergence resolved by the first relative tick; trim-drag pinning during release floods and cap breaches) per [AD110](../../documentation/decisions/README.md#ad110-terminal-scrolling-is-buffer-authoritative-on-every-route-held-output-ring-drops).

## 2026-07-18

- **Expired mobile sessions recover without a manual reload** ([REQ-AUTH-014](authentication.md#req-auth-014-auth-expiry-detection-mid-session), [REQ-AUTH-022](authentication.md#req-auth-022-session-expiry-on-resume-produces-a-clean-sign-in-redirect-never-a-blank-page), [REQ-MOB-009](mobile.md#req-mob-009-visibility-return-recovers-keyboard-state), [REQ-MOB-018](mobile.md#req-mob-018-decorative-webgl-canvas-retirement), [REQ-LANDING-001](landing.md#req-landing-001-mode-aware-public-landing-serving), and [REQ-LANDING-009](landing.md#req-landing-009-decorative-flare-failure-fallback); Implemented). Explicit, opaque, HTML, and Samsung-style status-zero auth failures start top-level sign-in; decorative WebGL retires on coarse-pointer backgrounding or context loss so the stable dark CSS surface remains visible.

- **Pi starts with compact canonical context and discovers specialized capabilities on demand** ([REQ-AGENT-007](agents.md#req-agent-007-multi-agent-adaptation-pipeline), [REQ-AGENT-065](agents.md#req-agent-065-engineering-constitution-preseeded-to-all-agents), [REQ-AGENT-095](agents.md#req-agent-095-compact-pi-skill-catalog), [REQ-AGENT-096](agents.md#req-agent-096-on-demand-pi-tool-activation), and [REQ-AGENT-097](agents.md#req-agent-097-bounded-pi-startup-context); Implemented). Canonical path rules become grouped Pi skills, proactive skills stay visible with compact trigger-preserving descriptions, one capability tool activates registered tools, event owners activate delegation before unchanged review and extraction follow-ups, and independent managed-seed and complete-runtime budgets bound startup context.

- **Pi review triage now checkpoints the reviewed head before fixes begin** ([REQ-AGENT-080](agents.md#req-agent-080-unified-pi-pr-boundary-launch-plan) and [REQ-AGENT-098](agents.md#req-agent-098-pi-review-triage-acknowledgement-barrier); Implemented). Reviewer results end in a mutation-free triage turn; settled enforcement requires the structural triage table after every successful reviewer notification before it writes the existing acknowledgement and starts a separate FIX follow-up, so the next pushed head is reviewed only from the acknowledged checkpoint.

- **Pi starts with context-mode disabled pending an upstream memory-safe adapter** ([REQ-AGENT-076](agents.md#req-agent-076-pi-context-mode-enablement-and-tool-extension-defaults) and [REQ-AGENT-089](agents.md#req-agent-089-pi-context-mode-foreground-ownership); Implemented). Fresh containers preserve the package for explicit `/ctx on` but disable its skills and adapter by default; every workflow retains its native fallback.

- **Per-AC test evidence now supports one or more named anchors** ([REQ-AGENT-094](agents.md#req-agent-094-per-ac-test-evidence-supports-multiple-anchors); Implemented). Every non-manual AC still requires resolving behavioral evidence, while multiple independently validated blocks or files may jointly verify one behavior.

- **Agent workflow traceability now separates graph reminders and Import Mode transition rules** ([REQ-AGENT-091](agents.md#req-agent-091-advanced-session-graph-first-runtime-reminders), [REQ-AGENT-092](agents.md#req-agent-092-import-transition-review-suppression), and [REQ-AGENT-093](agents.md#req-agent-093-import-mode-tdd-status-assignment); Implemented). Existing graph-first startup and soft-nudge behavior, transition-time review suppression, and TDD-aware imported-requirement status assignment now have dedicated requirements; runtime behavior is unchanged.

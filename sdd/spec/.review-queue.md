## Runtime gaps

<a id="hermes-checkpoint-predecessor"></a>
**Finding ID:** spec-claim-contradicted-1 (2026-11-22)
**Category:** spec-claim-contradicted
**Affected:** REQ-MEM-041 AC4

A failed checkpoint must preserve its predecessor. A directory flush can fail after replacement, so the current failure result does not establish that the predecessor survived. Close with evidence at the checkpoint/final-sync boundary; the standalone final-sync endpoint fixture does not cover it.

<a id="hermes-legacy-downgrade"></a>
**Finding ID:** spec-claim-contradicted-2 (2026-11-22)
**Category:** spec-claim-contradicted
**Affected:** REQ-MEM-041 AC5

Once isolation has initialized, a session must not return to master-backed writes. The current legacy adapter guard only detects a surviving checkout or checkpoint. A replacement container for an unchanged session can have neither. Close with evidence for that replacement-container case.

# Transitions and continuity

Read this for state changes, spatial continuity, choreography, and interruption.

## Preserve understanding

A transition should show what changed, where content came from or went, which element retains identity, and what receives attention next. Use cuts when continuity adds no information. Use spatial continuity when it reduces reorientation.

Choose duration and easing from distance, hierarchy, frequency, platform, and interruption. Entrances and exits need not mirror. Transform origin should follow perceived source only when that relationship is real.

## Coordinate without ceremony

Sequence only dependencies users need to understand. Simultaneous changes are often clearer than decorative stagger. Keep content available without waiting for animation completion, and do not let choreography delay frequent work.

For duplicated visual layers, shared-layout copies, or animated tab indicators, keep one accessible semantic control. Decorative copies must not duplicate focus, pointer behavior, names, or state ownership.

## Make motion interruptible

New intent should supersede stale motion safely. Define cancellation, reversal, retargeting, cleanup, and final state. Rapid input must not queue a long animation backlog or leave controls between states.

Test transitions with repeated actions, changed content, slow loading, long labels, focus movement, reduced motion, and navigation away. Preserve state and semantics when animation fails or is disabled.

# Communication and production artifact

> Added by Codeflare in 2026 as part of its modified Anthropic canvas-design skill.

Read this for event posters, campaign graphics, social or ad variants, information graphics, covers with required copy, signage, collateral, and print/screen artifacts whose primary job is communication.

## Structure the message

Establish audience, required action or understanding, mandatory and optional copy, brand commitments, viewing context and distance, dimensions, orientation, variants, screen or print delivery, localization, accessibility, and required formats.

Map content into a clear hierarchy. Preserve mandatory text character-for-character. Use authentic assets and claims. Design alternate crops and variants from one system rather than forcing one composition into every ratio.

## Match medium and production

When applicable, define:

- exact pixel or physical dimensions, orientation, and aspect ratio;
- effective raster resolution and intended viewing distance;
- screen color space or agreed print color/profile path;
- bleed, trim, crop marks, safe areas, and intentional edge bleed;
- transparency, compression, and file-size limits;
- PDF page, media, trim, and bleed boxes;
- font embedding or outlining, glyph coverage, and text editability;
- naming, page count, variants, and reproducible/editable source;
- accessibility descriptions or tagged output when required.

Do not claim CMYK conversion, embedded fonts, tagged PDF, print readiness, or editable source unless the output was actually produced and checked. If tooling cannot meet a required production condition, report it before delivery.

## Verify final output

Open every output and every PDF page when capability exists. Verify format, dimensions, orientation, page count, boxes, color mode, resolution, transparency, file size, font behavior, glyphs, mandatory copy, clipping, unintended overlap, bleed, trim, safe areas, contrast, and legibility at final size and expected distance.

Inspect alternate crops independently. Render again after correcting observed defects. Missing preflight capability narrows evidence; it does not create a pass.

# Frontend component routing

When visual frontend work introduces or refactors repeated component structure, load `frontend-components` when the runtime provides it. Otherwise apply this fallback boundary: extract only when ownership, coupling, state, reuse, testability, or maintenance improves; keep stable one-offs local.

`design` routes art direction to the applicable platform owner. `frontend-patterns` owns measured React and Next.js performance. Do not duplicate their methodology here.

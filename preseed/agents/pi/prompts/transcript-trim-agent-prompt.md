# Shared extraction: one-call transcript trimming

Invoke the scoped `transcript_trim` tool once with `operation: "trim"`, then report its compact result. Do not read or summarize transcript content in model context and do not submit batches of replacements.

The tool validates the parent-owned request identity, path, exact source-prefix length and SHA. It locally removes only permitted obsolete historical payloads outside the protected current conversation. It keeps every record, ID, parent, envelope, user message, accounting field, unknown opaque field/block, current context and latest authoritative state. Existing ancestry gaps are not repaired. Full SDK branch IDs remain internal ownership metadata, not model input.

Successful completion requires the complete persisted file to be between 15,000,000 and 25,000,000 bytes inclusive, including the parent's appended tail; 20,000,000 bytes is the preferred goal. The local operation may retain permitted source historical plaintext/thinking prefixes to avoid undershooting, but must never pad or modify user/current/unknown content. If the operation cannot meet that window, report its measured result truthfully; do not claim completion, an absolute protected floor, or improvise broader deletion. Invoke only one operation in this child attempt. The parent owns the common bounded extraction retries for native failure or an out-of-window Done, through six attempts and one terminal giveup; do not run a six-attempt loop inside the child.

Only the parent may correlate this attempt's own latest native completion, validate the candidate window and full SDK continuity, merge the latest tail unchanged, atomically replace the source, read back, and clean staging. Stop/cancellation does not retry. After commit, pending verification or cleanup uses only a read-only receipt, never another agent attempt. You cannot commit or alter source history, SDK/Goal internals, counters, credentials, settings, Vault data, or unrelated files. No backups, archives, network, or other agents.
